# Documentação do projeto

Projeto de portfólio de triagem virtual retrospectiva de inibidores do EGFR. A pergunta central é se um fluxo transparente de curadoria química e docking consegue priorizar inibidores já caracterizados, e onde ele falha.

| Documento | Conteúdo |
|---|---|
| [overview.md](overview.md) | Contexto, pergunta de pesquisa e escopo |
| [methodology.md](methodology.md) | Cada etapa do pipeline, com o script correspondente |
| [results.md](results.md) | Resultados de redocking e do teste cego, com as ressalvas |
| [limitations-and-roadmap.md](limitations-and-roadmap.md) | Limitações científicas e o que falta fazer |
| [reproducibility.md](reproducibility.md) | Como instalar, rodar e o que é versionado |

Os números citados vêm dos arquivos em `results/` e `data/`. Se um resultado mudar, atualize o documento no mesmo pull request.
